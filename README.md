## 🔭 What I'm Building

**🎧 Customer Support RAG Agent**
An agent that answers customer support queries by retrieving straight from a company's own knowledge base, with full tracing so every answer can be debugged and improved.
- Orchestration: **LangGraph**
- Retrieval: **Chroma** vector store
- Backend: **FastAPI** + **Supabase**
- Frontend: **Next.js**
- Observability: **LangSmith** tracing

**📈 Lead-Gen & CRM Automation Agent**
An agent that finds leads, enriches them, drafts personalized outreach, and syncs it all straight into a CRM — turning a manual prospecting workflow into a pipeline.
- CRM: **HubSpot** integration
- Enrichment: **Apollo.io** & **Clearbit**
- Orchestration: **n8n**
- AI-drafted, per-lead outreach
