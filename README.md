### 🧭 Fields I've worked across

**🛰️ Geospatial AI & Disaster Resilience**
- **[Route_Resilience](https://github.com/mithilSingh/Route_Resilience)** — Occlusion-aware road segmentation from satellite imagery, skeletonized into a routable NetworkX graph, stress-tested via betweenness-centrality "gatekeeper" detection, and served through a Streamlit + Folium dashboard with a live City Resilience Index.
- **ISRO Bharatiya Antariksh Hackathon 2025** (PS4 — chain-of-thought LLM systems for geoprocessing orchestration) — as part of a small team, helped build a LangChain tool-calling agent that pulls imagery from Sentinel Hub and ISRO's Bhoonidhi portal, derives NDVI/slope/DEM statistics with WhiteboxTools and GeoPandas, and classifies flood risk. ([`BAHPS4`](https://github.com/mithilSingh/BAHPS4))

**🤖 Robotics & Autonomous Systems**
- ROS 2 warehouse-navigation robot — led development (majority of commits) on a 3-person team's ~1,400-line node using Nav2 for path planning, LiDAR + camera sensor fusion, QR-code shelf identification, and a live Tkinter status GUI. ([`agamastic`](https://github.com/mithilSingh/agamastic))
- Team member on MANIT's entry to **NXP AIM India 2025**, an autonomous-vehicle racing competition.

**🚁 Drones / UAV**
- MAVLink + DroneKit flight-control scripts (arm, takeoff, velocity control, land), built up into an object-oriented `Drone` class designed to take live vision-based position feedback. ([`autonomous-drone-navigation`](https://github.com/mithilSingh/autonomous-drone-navigation))

**🧰 Full-Stack & Foundations**
- A multi-project sandbox spanning Flask web apps, a sockets-based multiplayer tic-tac-toe, an SVM digit classifier, a small game collection, and an OpenCV + Arduino colour-tracking servo rig. ([`codestocks`](https://github.com/mithilSingh/codestocks))
- Started here in 2020 with Python fundamentals — algorithms, Tkinter GUIs, TDD — before moving into everything above.
